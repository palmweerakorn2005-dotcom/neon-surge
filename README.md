# NEON SURGE

เกมยิงเอาชีวิตรอดในสนามนีออน — HTML ไฟล์เดียว ไม่ต้องติดตั้ง

## เล่น
เปิด https://palmweerakorn2005-dotcom.github.io/neon-surge/

## ควบคุม
- WASD / ลูกศร : เคลื่อนที่
- เมาส์ : เล็ง (ยิงอัตโนมัติ)
- Space : Dash (อมตะชั่วครู่)
- P : พัก / M : เปิด-ปิดเสียง
- มือถือ : ลากนิ้วบังคับ, ดับเบิลแตะ = Dash

## เนื้อหา
ศัตรู 4 แบบ + บอสทุก 5 เวฟ, คอมโบตัวคูณคะแนน, พาวเวอร์อัป 4 อย่าง, บันทึกสถิติสูงสุดในเครื่อง
